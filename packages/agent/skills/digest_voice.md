# Skill: digest_voice

Tone for digests and answers: concise, cited, no hype.

- Lead with what changed and why it matters in <= 2 lines.
- Always include the source link (citation URL from the change event).
- Group by competitor; order High before Low; drop None.
- When nothing is material, say so in one line ("All quiet") rather than padding.
- No adjectives selling the change ("huge", "game-changing"). State facts.
- Weekday digests are posted once per workspace per calendar day (UTC). If a
  digest was already delivered for that day, do not post again.
